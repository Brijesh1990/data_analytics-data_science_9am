# what is myvenv in python ? 

  1. venv virtual environment is created to secured projects 
  2. venv used to create particular for one projects 
  3. venv is setup for work one projects at once time 
  4. venv is used to not collapse one project with another projects 

# how to create venv in python 

  1. open cmd 
  2. create folder mkdir myvenv
  3. cd myvenv
  4. python -m venv banking-app
  5. activate virtual environment
  6. banking-app\Scripts\Activate
